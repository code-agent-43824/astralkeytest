# Передача работы

Мобильный вход с PKCE и системным окном iOS проверен с подменой ответа сервера. Следующий шаг — проверить артефакты CI, затем передать сборку владельцу для живого входа через CAPTCHA и копирования токена.

Сборки доступны в [GitHub Releases](https://github.com/code-agent-43824/astralkeytest/releases/latest). Следующая ручная проверка — открыть вход на Android или установить `Runner.app` из архива симулятора в запущенный Xcode Simulator и пройти вход с тестовым аккаунтом.

Ожидается решение владельца о встроенном OAuth-значении в `lib/main.dart`.
