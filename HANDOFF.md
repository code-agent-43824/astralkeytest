# Передача работы

Для ручной проверки OAuth взять Android APK или `Runner.app` для симулятора из [опубликованного релиза](https://github.com/code-agent-43824/astralkeytest/releases/latest). Пройти CAPTCHA и вход на demo, затем нажать «Копировать токен» на экране документов. Автоматические тесты проверили этот переход с подменой ответа сервера.

Ожидается решение владельца о встроенном OAuth-значении в `lib/main.dart`.
