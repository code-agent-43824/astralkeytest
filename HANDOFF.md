# Передача работы

В работе публикация версии из `pubspec.yaml`. Запустить штатный релизный workflow и проверить файлы в GitHub Releases.

Тестовая сборка `0.0.20` и нативные тесты на симуляторе Duo проверены. Для ручной проверки смены положения открыть приложение в Device Hub на iPhone Duo и переключить закрытую, полусложенную и раскрытую позы во время настройки PIN и просмотра документа. [Архив симулятора](https://github.com/code-agent-43824/astralkeytest/actions/runs/45882825948/artifacts/15148936871).

Ожидается решение владельца о встроенном OAuth-значении в `lib/main.dart`.
