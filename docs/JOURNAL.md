# Журнал выводов

## 2026-10-31 — Windows-сборка и новый MSVC

Гипотеза: `local_auth_windows` версии 1.0.11 включает экспериментальные корутины через `/await`, которые MSVC 14.51 блокирует без явного разрешения устаревшего заголовка.

Проверка: в журнале GitHub Actions ошибка `STL1011` исходила из цели `local_auth_windows_plugin`. После добавления определения компилятора только для этой цели Windows-сборка и загрузка артефакта прошли; Android и iOS тоже прошли.

Вывод: сбой был вызван несовместимостью старой версии плагина с обновлённым компилятором Windows runner. Настройка возвращает сборку, но в будущем потребуется обновить плагин до версии без экспериментальных корутин.

## 2026-10-31 — падение приветственного экрана

Гипотеза: тест остался от старой версии экрана, а фиксированная колонка не помещается по высоте.

Проверка: на размере теста Flutter сообщил о переполнении `RenderFlex` и не нашёл старый заголовок. После добавления прокрутки и проверки актуального экрана тест проходит на размере 320 × 568; анализатор чист, debug APK собирается.

Вывод: причина падения была в устаревших ожиданиях теста и отсутствии прокрутки у приветственного экрана.
