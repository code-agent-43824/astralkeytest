# Состояние

В GitHub Releases опубликована версия `0.0.18` для Android, Windows x64, устройства iOS и симулятора. Релизный архив симулятора содержит подписанный `Runner.app` с правами Keychain для Intel и Apple Silicon. [Релиз](https://github.com/code-agent-43824/astralkeytest/releases/tag/v0.0.18).

В `main` добавлена адаптивная вёрстка для современных iPhone. Виджет-тесты проверяют размеры обоих дисплеев iPhone Duo, поворот, узкое окно, крупный шрифт и сохранение хода входа при изменении размеров.

Отладочная подпись APK отличается от `0.0.17`, поэтому Android отклонит установку поверх предыдущей версии. Для установки сборки на устройство iOS потребуется подпись.

Приветственный экран прокручивается на небольшой высоте. Переход к авторизации на Android, iOS и Windows проверен виджет-тестами с заглушками. Анализатор чист, Android debug APK собирается.

В мобильном входе используется PKCE S256. iOS получает ответ через системное окно входа, Android — через callback из браузера. Приложение показывает разные сообщения при ошибке связи со стендом и ошибке хранилища. Получение и копирование токена проверены с подменой ответа сервера. На iOS Simulator прошёл нативный тест записи и чтения Keychain. Владелец подтвердил, что вход на `0.0.18` работает.

Строгая установка по `pubspec.lock` проверена на Flutter из облачной среды. В `lib/main.dart` остаётся встроенное значение для OAuth-клиента demo. Решение о его замене ожидается от владельца.
