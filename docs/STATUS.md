# Состояние

В CI собрана версия `0.0.18` для Android, Windows, устройства iOS и симулятора. Архив `ios-simulator` содержит подписанный `Runner.app` для Intel и Apple Silicon. Нативный тест записи и чтения Keychain на симуляторе прошёл. [Сборка CI](https://github.com/code-agent-43824/astralkeytest/actions/runs/45840026273).

В GitHub Releases опубликована версия `0.0.17`. Отладочная подпись её APK отличается от предыдущего релиза, поэтому установка поверх него недоступна. [Релиз](https://github.com/code-agent-43824/astralkeytest/releases/tag/v0.0.17).

Приветственный экран прокручивается на небольшой высоте. Переход к авторизации на Android, iOS и Windows проверен виджет-тестами с заглушками. Анализатор чист, Android debug APK собирается.

В мобильном входе используется PKCE S256. iOS получает ответ через системное окно входа, Android — через callback из браузера. Приложение показывает разные сообщения при ошибке связи со стендом и ошибке хранилища. Получение и копирование токена проверены с подменой ответа сервера. Вход с реальным аккаунтом в новой сборке ожидает ручной проверки.

Строгая установка по `pubspec.lock` проверена на Flutter из облачной среды. В `lib/main.dart` остаётся встроенное значение для OAuth-клиента demo. Решение о его замене ожидается от владельца.
