# Состояние

В GitHub Releases опубликована версия `0.0.19` для Android, Windows x64, устройства iOS и симулятора. Релизный архив симулятора содержит подписанный `Runner.app` с правами Keychain для Intel и Apple Silicon. [Релиз](https://github.com/code-agent-43824/astralkeytest/releases/tag/v0.0.19).

В CI собрана тестовая версия `0.0.20`. У приложения для устройства и подписанного архива симулятора SDK из `.xcode-version` подтверждён в `Info.plist` и Mach-O. На симуляторе Duo прошли тесты Keychain и подключения наблюдателя складки к окну Flutter. [Сборки CI](https://github.com/code-agent-43824/astralkeytest/actions/runs/45882825948).

Экраны входа, PIN и документов адаптируются к доступному месту. Виджет-тесты моделируют размеры обоих дисплеев iPhone Duo, поворот, узкое окно, крупный шрифт и появление складки. При изменении геометрии проверены сохранение PIN и открытого документа.

Опубликованные сборки `0.0.19` используют SDK 26.5 и запускаются на iPhone Duo в режиме совместимости. Для использования всей площади дисплеев Apple требует iOS SDK 27.1 или новее. [Требования Apple](https://developer.apple.com/iphone-duo/prepare/).

Отладочная подпись APK отличается от `0.0.18`, поэтому Android отклонит установку поверх предыдущей версии. Для установки сборки на устройство iOS потребуется подпись.

Приветственный экран прокручивается на небольшой высоте. Переход к авторизации на Android, iOS и Windows проверен виджет-тестами с заглушками. Анализатор чист, Android debug APK собирается.

В мобильном входе используется PKCE S256. iOS получает ответ через системное окно входа, Android — через callback из браузера. Приложение показывает разные сообщения при ошибке связи со стендом и ошибке хранилища. Получение и копирование токена проверены с подменой ответа сервера. На iOS Simulator прошёл нативный тест записи и чтения Keychain. Владелец подтвердил, что вход на `0.0.18` работает.

Строгая установка по `pubspec.lock` проверена на Flutter из облачной среды. В `lib/main.dart` остаётся встроенное значение для OAuth-клиента demo. Решение о его замене ожидается от владельца.
