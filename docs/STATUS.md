# Состояние

В [GitHub Releases](https://github.com/code-agent-43824/astralkeytest/releases/latest) опубликованы Android APK, Windows x64 и два архива iOS для устройства и симулятора.

Приветственный экран прокручивается на небольшой высоте. Переход к авторизации на Android, iOS и Windows проверен виджет-тестами с заглушками. Анализатор чист, Android debug APK собирается.

В CI добавлены виджет-тесты и сборка `ios-simulator` с архивом приложения. Для запуска архива нужен iOS Simulator из Xcode. Сценарий входа с реальным аккаунтом требует ручной проверки.

В мобильном входе используется PKCE S256. iOS получает ответ через системное окно входа, Android — через callback из браузера. Получение и копирование токена проверены с подменой ответа сервера. Для живого входа на demo нужно пройти CAPTCHA.

Строгая установка по `pubspec.lock` проверена на Flutter из облачной среды. В `lib/main.dart` остаётся встроенное значение для OAuth-клиента demo. Решение о его замене ожидается от владельца.
